I like understanding things all the way down — so I tend to build the layer everyone else imports. Neural-net runtimes with their own autodiff, tiny ML compilers with typed graph IR, MCP servers, order-book simulators, agent systems. If it's usually a black box, that's the part I want to open.

- 🔭 Building **[Intake](https://github.com/rayhankhilji)** — a proactive AI agent that helps UK students land degree apprenticeships: firm-specific CVs, application answers, and real-time voice mock interviews.
- 🧠 Happiest around **compilers, tensor IR, autodiff, agent architectures, and market microstructure**.
- 🌱 Currently going deeper on kernel fusion, inference-time systems, and evals for agent behaviour.
- 💬 Ask me about building ML frameworks from scratch, MCP, or optimal execution.
- ☕ building. scrolling. coffee. books. lego. monopoly enthusiast.

### What I'm building

| | |
|---|---|
| **[jellybean](https://github.com/rayhankhilji/jellybean)** | Token-efficient MCP server that gives agents structural understanding of a codebase — repo maps, symbol outlines, ranked search, import tracing. |
| **[tensorvm](https://github.com/rayhankhilji/tensorvm)** | A neural-network runtime built from scratch: tensor IR, reverse-mode autodiff, multiple compute backends, PyTorch-style Python API. |
| **[ForgeML](https://github.com/rayhankhilji/ForgeML)** | A miniature ML compiler — typed graph IR, fusion optimization, Triton kernel support. |
| **[Grove](https://github.com/rayhankhilji/Grove)** | An AI "personal CEO" for macOS: agent teams, workspace integration, an attention-ledger system. |
| **[orderflow-lob](https://github.com/rayhankhilji/orderflow-lob)** | A limit-order-book simulator for microstructure research and optimal-execution modelling. |
| **[ladder-standard](https://github.com/rayhankhilji/ladder-standard)** | A unit of inference measurement using Rasch-calibrated scales and verifiable administration. |
