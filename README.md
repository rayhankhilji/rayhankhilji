I'm an AI engineer and founder. I build with AI agents in the loop, so I get from an idea to a working system quickly and spend my real time on the parts that decide whether it lives or dies: what to build, how it should feel, and whether it holds up under load. I would rather ship something real and useful than take the long way round to prove a point.

Most of my energy right now goes into **Lumi** and **Intake**, an AI agent that helps UK students win degree apprenticeships. It keeps a living profile of each student, writes firm-specific CVs and application answers from their real experience, and runs live voice mock interviews trained on each firm's actual process.

Around that, I build smaller systems to really understand the stack I rely on. Neural network runtimes with their own autodiff, tiny ML compilers, MCP tooling for agents, order book simulators. If something is usually a black box, I like taking the lid off and rebuilding a small version of it so it stops being magic.

**How I work**
- AI in the loop for everything, from first draft to refactor. It is my default tool, not a party trick.
- Ship it, watch it break, fix it. Real feedback beats theory every time.
- Go one level deeper than I strictly need to, because that is where the actual understanding lives.

**Into:** AI agents, voice AI, LLM tooling, ML systems, compilers, market microstructure.

**Away from the keyboard:** coffee, books, lego, and a genuinely unreasonable enthusiasm for Monopoly.
